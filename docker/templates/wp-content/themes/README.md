# Plantilla de Temas Predeterminados

Coloca en este directorio cualquier tema personalizado o predeterminado que desees que esté disponible en cada nueva implementación del proyecto.

Cuando se ejecute `docker compose up` por primera vez con un directorio `web/wp-content` nuevo o vacío, los temas ubicados aquí se copiarán automáticamente a `web/wp-content/themes/`.
